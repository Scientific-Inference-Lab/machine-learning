Learning Types

자료에 관측된 출력 y가 있는지, 있다면 수인지 범주인지, 없다면 어떤 구조를 찾는지가 학습 유형을 가른다.

지도학습(supervised learning)입력 X와 관측된 출력 y의 관계를 학습한다.
비지도학습(unsupervised learning)출력 y 없이 입력 X의 구조를 찾는다.
판별 근거입력이 무엇인지가 아니라 관측된 출력의 유무·형태와 목표가 유형을 정한다.

자료와 목표가 학습 유형을 정한다

사례를 고르면 입력, 관측된 출력, 목표가 바뀌고 그에 따라 학습 유형과 과제가 정해진다.

겹치는 범주도 분류 문제다

두 범주가 입력 공간에서 겹친다는 사실은 문제 유형이 아니라 분류의 난이도를 바꾼다.

입력이 겹쳐도 범주로 된 출력 y가 주어져 있으므로 분류 문제다. 겹침은 완벽한 판정이 어려운 이유이지 군집화로 바뀌는 조건이 아니다.
