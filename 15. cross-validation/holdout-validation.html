Holdout Validation

자료를 학습 자료와 검증 자료(validation set)로 한 번 나누어 잰 검증 점수는 어떤 관측이 검증에 들어갔는지에 따라 달라진다. 검증 자료는 후보를 고르는 데 쓰고, 테스트 자료는 선택을 마친 모델을 마지막에 한 번 평가하는 데 쓴다.

학습 자료계수 같은 모델의 매개변수를 추정하는 데 쓴다.
검증 자료후보 모델과 설정을 비교해 고르는 데 쓴다.
테스트 자료선택에 쓰지 않고 고른 모델의 성능을 마지막에 평가한다.

같은 자료도 나누는 방식에 따라 검증 MSE가 달라진다

관측 40개를 20개씩 학습 자료와 검증 자료로 나눈다. 분할 번호를 바꾸면 검증에 들어가는 관측과 적합한 곡선이 바뀌고, 다항 차수를 바꾸면 같은 분할에서 후보 모델이 바뀐다.

검증 자료를 늘리면 학습 자료가 줄어 오차를 높게 추정할 수 있다

2차 모델로 고정하고 검증 자료 비율을 바꾸면 학습·검증 관측 수와, 열 번 다르게 나눈 검증 MSE의 평균과 흩어짐이 바뀐다.

테스트 결과로 모델을 고르면 최종 평가가 낙관적으로 치우친다

관측 40개를 학습 20개, 검증 10개, 테스트 10개로 나누고 1차부터 6차까지 비교한다. 차수를 고르는 데 쓴 자료를 바꾸면 고른 차수와 최종 성능으로 보고하는 값이 바뀐다.
