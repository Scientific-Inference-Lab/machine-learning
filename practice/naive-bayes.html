개념 확인: Naive Bayes

사전확률과 범주별 분포로 사후확률을 계산하고, 조건부 독립 가정의 대가를 판단한다.

문제 1

검사 양성의 의미

어떤 가상 질환의 유병률은 2%, 검사의 민감도는 0.95, 거짓 양성률은 0.08이다.

  1. P(+)와 P(질환 | +)를 구한다(소수 셋째 자리까지).
  2. 5,000명을 검사할 때 질환이 있는 양성 기대 인원, 질환이 없는 양성 기대 인원을 구하고 같은 사후확률을 다시 계산한다.
  3. 사후확률비 P(질환 | +)/P(질환 없음 | +)를 사전확률비와 조건부 확률의 비로 나누어 구하고, 같은 오분류 비용에서 무엇으로 분류하는지 적는다.
  4. 민감도가 0.95인데 양성 판정을 받은 사람의 질환 확률이 낮은 이유를 적는다.
해설 펼치기
  1. P(+) = 0.02 × 0.95 + 0.98 × 0.08 = 0.019 + 0.0784 = 0.0974, P(질환 | +) = 0.019/0.0974 ≈ 0.195다.
  2. 질환 있음 100명 중 95명, 질환 없음 4,900명 중 392명이 양성이다. 95/487 ≈ 0.195로 같다.
  3. (0.02/0.98) × (0.95/0.08) ≈ 0.242로 1보다 작으므로 ‘질환 없음’으로 분류한다.
  4. 질환이 드물어 질환이 없는 큰 집단에서 생기는 거짓 양성이 참 양성보다 많기 때문이다. 민감도 P(+ | 질환)와 사후확률 P(질환 | +)는 다른 질문이다.
문제 2

자료에서 추정하기

학습 관측 150개 중 범주 1이 45개, 범주 0이 105개다. 범주 1에 속한 관측 중 세 개의 특성값만 보면 2, 4, 6이다.

  1. 두 범주의 사전확률 추정값을 구한다.
  2. 범주 1에서 이 세 값만으로 정규분포의 평균과 분산을 최대우도 추정으로 구한다(분산은 n으로 나눈다).
  3. 두 범주의 조건부 분포를 고정하면, 범주 1을 선택하기 위해 f₁(x)/f₀(x)가 넘어야 하는 기준값을 구한다.
  4. 범주 균형을 위해 소수 범주를 복제해 50 : 50으로 맞춘 학습 자료에서 사전확률을 추정하면 생기는 문제를 적는다.
해설 펼치기
  1. π̂₁ = 45/150 = 0.3, π̂₀ = 105/150 = 0.7이다.
  2. 평균 4, 분산 ((−2)² + 0² + 2²)/3 = 8/3 ≈ 2.67이다.
  3. π₀/π₁ = 0.7/0.3 = 7/3 ≈ 2.33이다. 범주 1이 드물수록 필요한 밀도비가 커진다.
  4. 사전확률이 0.5로 추정되어 모집단의 실제 범주 비율을 반영하지 못하고 사후확률과 예측이 치우친다.
문제 3

조건부 독립으로 곱하기

이진 특성 두 개에 대해 다음 값을 추정했다.

범주πₖP(X₁ = 1 | k)P(X₂ = 1 | k)
10.30.80.5
00.70.20.4
  1. x₁ = 1, x₂ = 0인 관측에 대해 각 범주의 가중 확률과 범주 1의 사후확률을 구한다(소수 셋째 자리까지).
  2. 이 계산에 쓴 가정을 식으로 적는다.
  3. 한 범주 안에서 이진 특성 10개의 결합분포를 제약 없이 추정할 때와 조건부 독립을 가정할 때 자유 매개변수 수를 구한다.
  4. 범주 3개, 연속 특성 4개인 가우시안 나이브 베이즈가 추정하는 자유 매개변수 수를 구한다.
해설 펼치기
  1. 범주 1: 0.3 × 0.8 × 0.5 = 0.12. 범주 0: 0.7 × 0.2 × 0.6 = 0.084. 사후확률 0.12/0.204 ≈ 0.588이다.
  2. P(X₁, X₂ | k) = P(X₁ | k) × P(X₂ | k)로 범주가 주어졌을 때 특성이 조건부 독립이라고 둔다.
  3. 2¹⁰ − 1 = 1,023개와 10개다.
  4. 평균 3 × 4 = 12개, 분산 12개, 합이 1인 사전확률에서 2개로 26개다.
문제 4

밀도와 결정 경계

특성 하나에서 범주 0은 N(0, 1), 범주 1은 N(2, 1)을 따른다고 추정했다.

  1. π₀ = π₁일 때 결정 경계를 구한다.
  2. π₀ = 0.8, π₁ = 0.2일 때 f₁(x)/f₀(x) = exp(2x − 2)을 이용해 결정 경계를 구하고(소수 둘째 자리까지), 경계가 어느 쪽으로 움직였는지 적는다.
  3. f₁(1) ≈ 0.242를 ‘x = 1일 확률이 24.2%’라고 읽으면 왜 틀렸는지 적는다.
  4. 두 범주의 평균이 같고 분산이 1과 4로 다르면 결정 경계가 몇 곳일 수 있는지와 이유를 적는다.
해설 펼치기
  1. 두 밀도가 같은 x = 1이다.
  2. exp(2x − 2) > 4에서 x > 1 + (ln 4)/2 ≈ 1.69이다. 범주 1이 드물어 경계가 범주 1 쪽(오른쪽)으로 움직였다.
  3. 연속형 특성의 밀도는 한 점의 확률이 아니다.
  4. 두 곳일 수 있다. 가운데에서는 분산이 작은 범주의 밀도가, 양쪽 꼬리에서는 분산이 큰 범주의 밀도가 커서 곡선이 두 번 교차한다.
문제 5

가정이 휠 때

두 시차 수익률로 다음 날 방향을 예측한 가우시안 나이브 베이즈의 테스트 결과(250일)다.

실제 하락실제 상승
하락 예측3025
상승 예측70125
  1. 정확도를 구하고, 항상 ‘상승’으로 예측하는 기준모델의 정확도와 비교한다.
  2. 거의 같은 특성을 하나 더 넣으면 나이브 베이즈에서 무엇이 잘못될 수 있고 무엇을 점검하는지 적는다.
  3. 전체 자료에서 두 특성의 상관이 크다는 사실만으로 조건부 독립이 깨졌다고 결론 내릴 수 없는 이유를 적는다.
  4. 범주 선택 성능과 사후확률 값 자체의 품질을 각각 무엇으로 확인하는지 적고, 로지스틱 회귀와 모델링 대상이 어떻게 다른지 적는다.
해설 펼치기
  1. (30 + 125)/250 = 0.62다. 실제 상승이 150일이므로 기준모델은 0.6이며 차이는 0.02다.
  2. 같은 증거를 두 번 세어 확률이 과도하게 극단적일 수 있다. 같은 분할에서 검증 성능과 확률 추정의 품질을 비교한다.
  3. 범주별 평균이 다르면 범주를 합친 자료에서 특성이 연관되어 보일 수 있다. 조건부 독립은 같은 범주 안에서 확인한다.
  4. 범주 선택은 혼동행렬과 목적에 맞는 분류 지표로, 확률 값은 예측 확률과 실제 발생 비율의 일치로 확인한다. 나이브 베이즈는 범주별 특성 분포와 사전확률을, 로지스틱 회귀는 특성이 주어졌을 때의 범주 확률을 직접 모델링한다.
