개념 확인: Nearest Neighbors and Support Vectors

거리로 이웃을 찾는 kNN과 마진으로 경계를 정하는 SVM을 계산하고 설정을 판단한다.

문제 1

이웃 찾기

새 관측 x₀ = (나이 30, 검사 수치 120)이다. 학습 관측 다섯 개와 범주는 다음과 같다.

관측나이검사 수치범주
A33124Y
B28121N
C31110Y
D50125N
E29117Y
  1. 각 관측까지의 유클리드 거리를 구한다(소수 둘째 자리까지).
  2. K = 1과 K = 3일 때 예측 범주를 적는다.
  3. 검사 수치에만 10을 곱해 적으면(x₀는 1,200) 각 거리를 다시 구하고(소수 둘째 자리까지), 가까운 순서에서 달라지는 점을 적는다.
  4. 이런 변화를 막기 위해 무엇을 하는지 적는다.
해설 펼치기
  1. A 5.00, B √5 ≈ 2.24, C √101 ≈ 10.05, D √425 ≈ 20.62, E √10 ≈ 3.16.
  2. K = 1은 B로 N. K = 3은 B, E, A로 N 1표, Y 2표이므로 Y.
  3. A 40.11, B 10.20, C 100.00, D 53.85, E 30.02다. 네 번째로 가까운 관측이 C에서 D로 바뀐다. 검사 수치의 차이가 거리를 지배하기 때문이다.
  4. 학습 자료에서 추정한 평균·표준편차로 특성의 척도를 맞춘다.
문제 2

K 고르기

  1. K = 1과 K = 100의 결정 경계와 편향·분산 경향을 비교한다.
  2. 학습 관측 자신을 이웃에 포함해 K = 1의 학습 정확도를 계산하면 값이 얼마가 되기 쉬운지와 그 결과로 K를 고르면 안 되는 이유를 적는다.
  3. 관련 특성 2개에 무관한 특성 50개를 추가하면 kNN에 어떤 일이 생기는지 적는다.
  4. 홀수 K가 해결하는 동률과 해결하지 못하는 동률을 각각 적는다.
해설 펼치기
  1. K = 1은 개별 점에 민감한 불규칙한 경계로 분산이 크고, K = 100은 매끈한 경계로 편향이 커질 수 있다.
  2. 자기 자신이 가장 가까운 이웃이라 학습 정확도가 1에 가까워진다. 학습 정확도는 일반화 성능이 아니므로 교차검증 점수로 비교한다.
  3. 무관한 차이가 거리에 누적되어 가까운 이웃을 구별하기 어려워지고, 가까운 이웃을 확보하려면 더 많은 관측이 필요할 수 있다.
  4. 이진 범주의 표 수 동률은 피하지만, K번째와 그다음 이웃의 거리가 같아 누구를 포함할지 모호한 문제는 해결하지 못한다.
문제 3

kNN 코드와 평가

5,822개 관측에서 1,000개를 테스트로 떼고 다음 코드로 K를 골랐다.

pipe = make_pipeline(StandardScaler(), KNeighborsClassifier())
search = GridSearchCV(
    pipe, {"kneighborsclassifier__n_neighbors": [1, 3, 5]},
    scoring="accuracy", cv=cv)
search.fit(Xtr, ytr)
  1. StandardScaler를 pipeline 안에 둔 이유를, 전체 자료로 먼저 척도를 학습할 때와 비교해 적는다.
  2. 테스트 자료에서 가입자(Yes)가 60명일 때 모두 No로 예측하는 모델의 정확도와 재현율을 구한다.
  3. 선택된 모델이 테스트 정확도 0.93, 가입자 60명 중 4명을 찾았다. 재현율을 구하고 정확도만으로 평가하면 놓치는 점을 적는다.
  4. 테스트 결과를 보고 K 후보를 [7, 9, 11]로 바꿔 다시 고르면 생기는 문제를 적는다.
해설 펼치기
  1. 각 분할의 학습 부분에서만 평균과 표준편차를 구하고 검증 부분에는 그 변환만 적용하기 위해서다. 전체 자료로 먼저 학습하면 검증 자료 정보가 전처리에 새어 들어간다.
  2. 정확도 940/1,000 = 0.94, 재현율 0/60 = 0.
  3. 4/60 ≈ 0.067이다. 정확도 0.93은 모두 No로 답하는 기준모델보다도 낮고, 가입자를 거의 찾지 못한다는 사실이 정확도에 드러나지 않는다.
  4. 테스트 자료가 선택에 쓰여 독립적인 최종 평가가 아니게 된다.
문제 4

초평면과 마진

초평면 f(x) = −2 + 3x₁ + 4x₂ = 0으로 학습 관측 세 개를 분리한다.

관측x₁x₂범주
P21+1
Q00−1
R1−1−1
  1. 각 관측의 f(x) 값과 초평면까지의 거리 |f(x)|/‖β‖₂를 구한다.
  2. 세 관측이 모두 올바른 쪽에 있는지 확인하고, 이 초평면의 마진을 구한다.
  3. P에 ‖δ‖₂ < 1.6인 변화를 더해도 분류가 바뀌지 않는 이유를 적는다.
  4. 최대 마진 경계에서는 일반적으로 마진 위에 있지 않은 점을 조금 옮기면 경계가 바뀌는지 적고 서포트 벡터와 연결한다.
해설 펼치기
  1. ‖β‖₂ = √(3² + 4²) = 5. P: f = 8, 거리 1.6. Q: f = −2, 거리 0.4. R: f = −3, 거리 0.6.
  2. P는 양수로 +1, Q와 R은 음수로 −1이므로 모두 올바르다. 마진은 가장 가까운 거리 0.4다.
  3. 초평면까지의 거리보다 작은 변화로는 f의 부호가 바뀌지 않는다.
  4. 마진 바깥의 점은 그 영역에 머무르는 한 경계를 바꾸지 않는다. 경계는 마진 위의 서포트 벡터가 결정한다.
문제 5

실제 SVM 설정

  1. 소프트 마진에서 ‘마진 위반’과 ‘오분류’의 차이를 적는다.
  2. SVC의 C를 작게 할 때와 크게 할 때 학습이 중시하는 것과 각각 확인할 점을 적는다. C가 마진 위반 비용의 계수인 경우와 위반 허용량으로 정의된 경우, C를 키울 때 위반을 허용하는 정도가 어떻게 달라지는지 비교한다.
  3. 중앙에 한 범주가 모이고 양쪽에 다른 범주가 있는 자료에서 선형 커널과 RBF 커널의 경계 차이를 적는다.
  4. kNN과 SVM이 예측할 때 각각 무엇을 사용하는지 적고, 두 모델을 비교할 때 같게 맞춰야 할 조건 두 가지를 적는다.
해설 펼치기
  1. 마진 위반은 관측이 마진 안쪽에 들어온 것이고, 오분류는 경계 반대편에 있는 것이다. 모든 오분류는 위반이지만 모든 위반이 오분류는 아니다.
  2. SVC에서 작은 C는 위반을 감수하고 넓은 마진을 확보하므로 지나치게 단순해지지 않는지, 큰 C는 학습 자료의 위반을 줄이므로 개별 점에 과도하게 맞추지 않는지 확인한다. SVC의 C는 마진 위반 비용의 계수이므로 키우면 위반을 더 강하게 억제한다. C를 위반 허용량으로 정의한 경우에는 키울수록 더 많은 위반을 허용한다.
  3. 선형 커널은 원래 특성 공간에서 초평면만 만들 수 있어 많은 점을 오분류하고, RBF 커널은 곡선 경계를 만들 수 있다.
  4. kNN은 새 점의 가까운 K개 이웃의 다수결을, SVM은 서포트 벡터로 정해진 결정 함수의 부호를 쓴다. 같은 자료 분할과 같은 척도 조정 조건에서 비교한다.
