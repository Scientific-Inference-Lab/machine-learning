개념 확인: Ensemble Methods

여러 나무를 평균하거나 순차적으로 더할 때 분산과 오차가 어떻게 바뀌는지 계산하고 판단한다.

문제 1

부트스트랩 표본

원 자료가 관측 1~5이고, 복원추출로 만든 부트스트랩 표본이 (4, 1, 4, 2, 4)다.

  1. 이 표본에서 빠진 관측을 적는다.
  2. n = 5와 n = 100일 때 특정 관측이 한 부트스트랩 표본에서 한 번도 뽑히지 않을 확률을 구한다(소수 셋째 자리까지). n이 커질 때의 극한도 적는다.
  3. 관측 1,000개로 만든 표본 하나에서 빠지는 관측이 정확히 368개라고 말할 수 없는 이유를 적는다.
  4. 관측 3의 OOB 예측을 만들 때 어떤 나무들을 쓰는지, OOB 오차가 별도 테스트 자료의 오차와 어떻게 다른지 적는다.
해설 펼치기
  1. 3과 5다.
  2. n = 5: (4/5)⁵ ≈ 0.328. n = 100: (0.99)¹⁰⁰ ≈ 0.366. 극한은 1/e ≈ 0.368이다.
  3. n이 클 때 약 36.8%는 빠진 관측의 기대 비율이며, 매 표본에서 그 비율이 고정되지는 않는다.
  4. 관측 3이 부트스트랩 표본에 들어가지 않은 나무들만으로 예측을 결합한다. OOB 오차는 따로 떼어 둔 자료 없이 테스트 오차를 추정하지만, 설정을 모두 정한 뒤의 최종 평가는 별도로 보관한 테스트 자료로 한다.
문제 2

평균이 줄이는 분산

한 입력에서 각 나무 예측의 분산이 σ² = 4이고, 서로 다른 두 나무 예측의 상관계수가 모두 ρ다.

  1. ρ = 0, B = 25일 때 평균 예측의 분산을 구한다.
  2. ρ = 0.5, B = 25일 때 분산을 구하고, B를 아무리 늘려도 남는 값을 구한다.
  3. ρ = 0.1일 때 B = 25와 B = 100의 분산을 구한다(소수 셋째 자리까지).
  4. 같은 학습 자료로 만든 깊은 나무들을 배깅할 때 ρ = 0을 가정하면 안 되는 이유와, 랜덤 포레스트가 이 식의 어느 항을 줄이려 하는지 적는다.
해설 펼치기
  1. σ²/B = 4/25 = 0.16이다.
  2. 4 × (0.5 + 0.5/25) = 2.08이고, B → ∞에서 ρσ² = 2가 남는다.
  3. B = 25: 4 × (0.1 + 0.9/25) = 0.544. B = 100: 4 × (0.1 + 0.9/100) = 0.436.
  4. 같은 자료에서 나온 부트스트랩 표본은 겹치고 강한 특성이 비슷한 분할을 만들어 나무 예측이 상관된다. 랜덤 포레스트는 분할 후보를 줄여 ρ를 낮춘다.
문제 3

예측 결합과 나무 수

  1. 회귀 나무 세 그루가 한 입력에 12, 15, 9를 예측했다. 배깅 예측값을 구한다.
  2. 분류 나무 세 그루가 한 입력에서 범주 A의 확률을 0.9, 0.4, 0.4로 추정했다. 각 나무가 0.5 기준으로 투표하는 다수결 결과와 확률을 평균한 뒤 큰 범주를 고르는 결과를 각각 구한다.
  3. scikit-learn의 RandomForestClassifier는 둘 중 어느 방식을 쓰는지 적는다.
  4. OOB 오차가 나무 200그루 이후 거의 평평해졌다. 나무를 2,000그루로 늘릴지 판단할 때 비교할 두 가지를 적는다.
해설 펼치기
  1. (12 + 15 + 9)/3 = 12다.
  2. 다수결: A, B, B로 B. 확률 평균: (0.9 + 0.4 + 0.4)/3 ≈ 0.567로 A.
  3. 나무별 확률을 평균한 뒤 가장 큰 범주를 고른다.
  4. 나무를 더해 얻는 예측 안정성과 늘어나는 계산량(실행 시간)을 비교한다. 나무 수가 충분해진 뒤에는 검증 오차가 계속 좋아지지 않는다.
문제 4

랜덤 포레스트

  1. 랜덤 포레스트의 두 가지 무작위 추출이 각각 무엇을, 언제 뽑는지 적는다.
  2. 특성이 p = 16개인 분류 문제에서 흔히 쓰는 시작값 m을 구하고, m = 16으로 두면 어떤 방법과 같아지는지 적는다.
  3. m을 매우 작게(예: 1) 하면 얻을 수 있는 이득과 위험을 적는다.
  4. 두 특성이 강하게 상관되어 있을 때 불순도 기반 중요도가 한쪽만 크게 나왔다. 이를 ‘다른 특성은 영향이 없다’거나 ‘이 특성의 인과 효과가 크다’로 읽으면 안 되는 이유를 적는다.
해설 펼치기
  1. 관측은 나무마다 부트스트랩 표본으로, 특성은 각 분할에서 후보 m개를 뽑는다.
  2. m ≈ √16 = 4다. 다른 조건이 같다면 m = p는 의사결정나무 배깅과 같다.
  3. 나무 사이 상관을 줄일 수 있지만, 유용한 특성이 후보에서 빠져 좋은 분할을 놓칠 수 있다. m은 검증으로 정한다.
  4. 불순도 감소량은 인과 효과의 크기가 아니며, 상관된 특성에서는 중요도가 한쪽에 집중되거나 나뉠 수 있고 자료나 난수에 따라 순위가 바뀔 수 있다.
문제 5

부스팅과 비교

제곱오차 회귀 부스팅에서 y = (3, 5, 10)이고 f̂₀ = ȳ에서 시작한다. 첫 나무 h₁은 앞의 두 관측에 −2, 세 번째 관측에 4를 예측한다.

  1. f̂₀와 첫 잔차를 구한다.
  2. 학습률 λ = 0.5일 때 f̂₁과 새 잔차를 구한다.
  3. 같은 층화 5-fold에서 균형 정확도가 의사결정나무 학습 1.000·검증 0.747, 랜덤 포레스트 1.000·0.826, 부스팅 0.995·0.785였다. 이 결과로 말할 수 있는 것과 말할 수 없는 것을 각각 적는다.
  4. 배깅과 부스팅의 병렬 학습 가능 여부를 비교하고, ‘병렬로 학습하므로 나무 예측이 통계적으로 독립이다’가 틀린 이유를 적는다.
해설 펼치기
  1. f̂₀ = 6, 잔차 (−3, −1, 4)다.
  2. f̂₁ = 6 + 0.5 × (−2, −2, 4) = (5, 5, 8), 새 잔차 (−2, 0, 2)다.
  3. 이 설정과 분할에서 랜덤 포레스트의 검증 평균이 가장 높고 세 모델 모두 학습 점수와 차이가 크다고 말할 수 있다. 조정 후의 최종 테스트 성능이나 모든 자료에서의 우열은 말할 수 없다.
  4. 배깅·랜덤 포레스트는 다른 나무를 기다리지 않아 병렬 학습이 가능하고, 부스팅은 이전 단계를 보완하므로 순서가 필요하다. 병렬 학습 가능 여부와 예측의 통계적 독립성은 다른 개념이며, 같은 자료에서 나온 나무들은 상관될 수 있다.
