개념 확인: Maximum Likelihood Estimation

관측을 고정하고 매개변수를 바꾸는 우도를 계산해 최대우도 추정값을 구하고, 이미 배운 모델과 연결한다.

문제 1

우도는 함수다

문제 1~2는 독립인 이진 관측 8개 중 성공(y = 1)이 6개인 자료를 쓴다.

  1. 성공 확률을 θ로 둘 때 관측한 특정 순서의 우도 L(θ)를 식으로 적는다.
  2. L(0.5)와 L(0.75)를 구하고 L(0.75)/L(0.5)를 구한다(소수 셋째 자리까지).
  3. ‘L(0.75)가 더 크므로 θ = 0.75일 확률이 더 크다’는 해석의 문제를 적는다.
  4. 확률분포와 우도가 각각 무엇을 고정하고 무엇을 변수로 두는지, 무엇에 대해 합이 1이어야 하는지 적는다.
해설 펼치기
  1. L(θ) = θ⁶(1 − θ)²이다.
  2. L(0.5) = 0.5⁸ = 1/256 ≈ 0.0039, L(0.75) = 0.75⁶ × 0.25² ≈ 0.0111, 비는 ≈ 2.848이다.
  3. 우도는 매개변수 θ 자체의 확률이 아니다. 관측 자료를 고정했을 때 θ 값들의 상대적 적합도를 비교할 뿐이다.
  4. 확률분포는 θ를 고정하고 자료값을 변수로 두며 자료값에 대해 합이나 적분이 1이다. 우도는 자료를 고정하고 θ를 변수로 두며 θ에 대해 1일 필요가 없다.
문제 2

로그 우도로 최대화

문제 1의 성공 6회인 자료를 사용한다. 로그는 자연로그다.

  1. 로그 우도 ℓ(θ)를 적고 ℓ′(θ) = 0을 풀어 MLE를 구한다.
  2. ℓ(θ)를 최대화한 θ와 L(θ)를 최대화한 θ가 같은 이유를 적는다.
  3. 8번 모두 성공이었다면 L(θ)와 MLE를 적고, 미분값 0으로 구하지 않는 이유를 적는다.
  4. 독립 관측 1,100개의 확률이 모두 0.5일 때 Python float로 곱을 계산한 값과 로그의 합을 적고(로그의 합은 소수 첫째 자리까지), 로그를 쓰는 이유 두 가지를 적는다.
해설 펼치기
  1. ℓ(θ) = 6 ln θ + 2 ln(1 − θ). ℓ′(θ) = 6/θ − 2/(1 − θ) = 0에서 6(1 − θ) = 2θ, θ̂ = 6/8 = 0.75다.
  2. 자연로그는 양수에서 증가함수라 순서를 보존하기 때문이다.
  3. L(θ) = θ⁸은 [0, 1]에서 증가하므로 θ̂ = 1이다. 최대점이 구간 내부가 아니라 경계에 있어 내부 미분값이 0이 되지 않는다.
  4. 곱은 0.0으로 계산되고 로그의 합은 1,100 × ln 0.5 ≈ −762.5다. 곱을 합으로 바꿔 계산과 미분이 쉬워지고, 작은 확률의 곱이 0으로 반올림되는 문제를 피한다.
문제 3

정규분포와 수치 갱신

독립이고 같은 정규분포를 따른다고 가정한 관측이 3, 5, 7, 9다.

  1. μ와 σ²의 MLE를 구한다.
  2. 분모가 n − 1인 표본분산을 구하고(소수 셋째 자리까지) MLE와 다른 점을 적는다.
  3. 문제 2의 베르누이 로그 우도에서 θ₀ = 0.6, 학습률 η = 0.01로 음의 로그 우도에 경사하강 한 번을 적용한 θ₁을 구한다.
  4. 해석적 해가 없어 수치 최적화로 MLE를 구할 때 확인할 것 두 가지를 적는다.
해설 펼치기
  1. μ̂ = 24/4 = 6, σ̂² = (9 + 1 + 1 + 9)/4 = 5다.
  2. 20/3 ≈ 6.667이다. MLE의 분산은 분모가 n이다.
  3. ℓ′(0.6) = 6/0.6 − 2/0.4 = 5. θ₁ = θ₀ − η × (−5) = 0.6 + 0.01 × 5 = 0.65다.
  4. 목적함수의 방향(최대화인지 최소화인지)과 제약조건, 수렴 여부를 확인한다. 후보가 최대점인지와 경계 값도 확인한다.
문제 4

이미 배운 모델 속 MLE

  1. 선형 회귀에서 어떤 오차 가정을 두면 최소제곱 계수가 MLE와 같은지 적고, −ℓ(β)의 식에서 그 이유를 설명한다.
  2. 정규화 벌점이 없는 로지스틱 회귀의 음의 로그 우도와 관측별 로지스틱 손실의 관계를 적는다.
  3. 가우시안 나이브 베이즈의 사전확률·평균·분산 기본 추정값이 무엇의 MLE인지 적는다.
  4. ridge 벌점 λ‖β‖²를 더한 로지스틱 회귀의 해를 ‘MLE’라고 부르면 안 되는 이유와, 우도가 높다는 것만으로 모델을 믿을 수 없는 이유 하나를 적는다.
해설 펼치기
  1. 오차가 서로 독립이고 같은 분산의 정규분포 N(0, σ²)를 따를 때다. −ℓ(β) = (1/(2σ²))Σ(yᵢ − xᵢᵀβ)² + C이고 C는 β와 무관하므로 RSS 최소화와 같다.
  2. 음의 로그 우도는 관측마다의 로지스틱 손실 −yᵢ log pᵢ − (1 − yᵢ) log(1 − pᵢ)를 더한 값이다.
  3. 사전확률과 범주별 정규분포의 매개변수를 최대우도로 추정한 값이다.
  4. λ > 0이면 우도만이 아니라 적합도와 계수 크기를 함께 최소화하므로 MLE와 목적함수가 다르다. 분포 가정이 틀리거나 새 자료에서 예측 성능이 유지되지 않을 수 있다.
문제 5

생성과 판별

이진 특성 x 하나와 범주 y에 대해 P(y = 1) = 0.3, P(x = 1 | y = 1) = 0.8, P(x = 1 | y = 0) = 0.25로 추정했다.

  1. x = 1과 x = 0 각각에서 P(y = 1 | x)를 구한다(소수 셋째 자리까지).
  2. 이 계산이 생성 모델 방식인 이유와, 로지스틱 회귀는 무엇을 직접 추정하는지 적는다.
  3. 가우시안 나이브 베이즈와 로지스틱 회귀가 최대화하는 우도를 각각 적는다.
  4. 어떤 테스트 자료에서 나이브 베이즈 정확도가 0.595, 로지스틱 회귀가 0.560이었다. 이 결과만으로 ‘나이브 베이즈가 더 좋은 방법’이라고 할 수 없는 이유와, 자료가 적을 때 분포 가정이 도움이 되는 조건을 적는다.
해설 펼치기
  1. x = 1: 0.24/(0.24 + 0.175) ≈ 0.578. x = 0: 0.06/(0.06 + 0.525) ≈ 0.103.
  2. 사전확률과 범주별 특성 분포로 결합확률을 만든 뒤 베이즈 정리로 사후확률을 계산했기 때문이다. 로지스틱 회귀는 P(y = 1 | x)를 직접 추정한다.
  3. 나이브 베이즈는 결합분포의 우도 Πᵢ f(xᵢ | yᵢ)P(yᵢ)(f는 범주별 조건부 밀도), 로지스틱 회귀는 조건부 우도 ΠP(Y = yᵢ | xᵢ)를 최대화한다.
  4. 한 번의 테스트 결과를 모든 자료로 일반화할 수 없다. 분포 가정이 자료와 맞을 때 추정을 안정시킬 수 있다.
