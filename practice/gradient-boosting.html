개념 확인: Gradient Boosting

한 단계의 잔차 적합과 로그 승산 갱신을 직접 계산하고, 학습률·나무 수·깊이와 구현을 고르는 근거를 점검한다.

문제 1

회귀의 첫 단계

특성 x = 1, 2, 3, 4, 5, 6에 대한 목표값이 y = 1, 3, 8, 10, 12, 14다. 시작 예측 f0은 학습 자료의 평균이고, 깊이 1 회귀 트리가 잔차를 목표로 분할 하나를 고른다. 학습률은 λ = 0.1이다.

분할왼쪽 잔차 평균오른쪽 잔차 평균잔차 제곱합
x ≤ 1.5−71.471.2
x ≤ 2.5(가)(나)(다)
x ≤ 3.5−4434
x ≤ 4.5−2.5555
x ≤ 5.5−1.2686.8
  1. f0과 여섯 관측의 잔차를 구한다.
  2. 표의 (가)·(나)·(다)를 채우고, 이 단계에서 고르는 분할을 적는다.
  3. x = 1과 x = 4의 새 예측 f1을 구한다.
  4. 학습 MSE는 약 21.67에서 약 18.25로 줄었다. λ = 1이었다면 같은 분할로 더 크게 줄었을 텐데도 작은 학습률을 쓰는 까닭을 설명한다.
해설 펼치기
  1. f0 = (1 + 3 + 8 + 10 + 12 + 14) / 6 = 8이고 잔차 y − f0는 −7, −5, 0, 2, 4, 6이다.
  2. x ≤ 2.5의 왼쪽 잔차는 −7, −5라서 평균이 (가) −6, 오른쪽 잔차는 0, 2, 4, 6이라서 평균이 (나) 3이다. 잔차 제곱합은 (1 + 1) + (9 + 1 + 1 + 9) = (다) 22다. 다섯 분할 가운데 제곱합이 가장 작으므로 x ≤ 2.5를 고른다.
  3. 나무는 왼쪽에 −6, 오른쪽에 3을 예측한다. x = 1은 8 + 0.1 × (−6) = 7.4, x = 4는 8 + 0.1 × 3 = 8.3이다.
  4. λ = 1이면 이 분할로 줄일 수 있는 만큼을 한 번에 줄인다. 작은 학습률은 한 나무의 수정량 가운데 일부만 반영하고 나머지를 다음 나무들이 조금씩 고치게 한다. 그만큼 나무가 더 필요하지만 한 나무의 분할에 과하게 끌려가지 않으며, 검증 오차를 보면서 멈출 단계를 고를 여지가 생긴다.

흔한 오답은 잎의 값을 잔차가 아니라 y의 평균(왼쪽 2, 오른쪽 11)으로 계산하는 것이다. 첫 나무 이후의 나무는 목표값이 아니라 현재 예측이 남긴 잔차를 맞춘다.

문제 2

분류의 첫 단계

관측 4개의 정답이 y = 0, 1, 1, 1이다(x = 1, 2, 3, 4). 시작 로그 승산은 f0 = log(ȳ / (1 − ȳ))이고, 첫 나무는 분할 x ≤ 1.5를 골랐다. 학습률은 λ = 0.5다.

  1. f0과 모든 관측의 시작 확률 p, 그리고 나무가 목표로 삼는 r = y − p를 구한다.
  2. 잎의 값 γ = Σr / Σp(1 − p)를 왼쪽 잎과 오른쪽 잎에 대해 구한다.
  3. 두 구간의 f1 = f0 + λγ와 p1 = σ(f1)을 소수 셋째 자리까지 구한다.
  4. 한 학생이 로그 승산 대신 확률에 직접 p + λγ를 더하자고 했다. 오른쪽 잎에서 이 방식이 어떤 문제를 만드는지 설명한다.
해설 펼치기
  1. ȳ = 0.75이므로 f0 = log(0.75 / 0.25) = log 3 ≈ 1.099, 모든 관측의 p = 0.75다. r는 −0.75, 0.25, 0.25, 0.25다.
  2. 모든 관측에서 p(1 − p) = 0.1875다. 왼쪽 잎은 관측 하나라 γ = −0.75 / 0.1875 = −4, 오른쪽 잎은 γ = 0.75 / (3 × 0.1875) ≈ 1.333이다.
  3. 왼쪽은 f1 ≈ 1.099 + 0.5 × (−4) = −0.901, p1 ≈ 0.289다. 오른쪽은 f1 ≈ 1.099 + 0.5 × 1.333 = 1.765, p1 ≈ 0.854다. 정답이 0인 관측의 확률은 내려가고 정답이 1인 관측의 확률은 올라갔다.
  4. 오른쪽 잎에서 0.75 + 0.5 × 1.333 ≈ 1.417이 되어 확률의 범위를 벗어난다. 로그 승산 f는 어떤 실수여도 σ(f)가 0과 1 사이에 있으므로, 나무의 기여는 로그 승산에 더하고 마지막에 확률로 되돌린다.

흔한 오답은 잎의 값을 잔차 평균(왼쪽 −0.75, 오른쪽 0.25)으로 두는 것이다. 로그 손실에서는 잔차 합을 p(1 − p)의 합으로 나눈 값을 쓴다.

문제 3

학습률과 나무 수

어떤 회귀 자료를 학습·검증·테스트 자료로 나누고, 깊이 3 나무를 최대 1000그루까지 더하며 단계마다 검증 MSE를 기록했다.

학습률검증 MSE가 가장 작은 나무 수최소 검증 MSE1000그루에서의 검증 MSE
0.33512.414.1
0.0524011.912.5
0.01100012.612.6
  1. 학습률과 필요한 나무 수 사이의 관계를 표에서 읽는다.
  2. 한 학생이 “학습률 0.01의 최소 검증 MSE가 가장 크므로 작은 학습률은 성능을 떨어뜨린다”고 결론 내렸다. 표에서 이 결론을 받아들이기 어려운 근거를 찾는다.
  3. 같은 학생이 학습률 0.05, 나무 240그루를 고른 뒤 11.9를 최종 성능으로 보고했다. 무엇이 잘못되었고 무엇을 보고해야 하는지 설명한다.
해설 펼치기
  1. 이 표에서 학습률을 0.3에서 0.05, 0.01로 낮추자 검증 MSE가 가장 작은 나무 수가 35, 240, 1000으로 늘었다.
  2. 학습률 0.01은 최솟값이 허용한 최대 나무 수 1000에서 나왔고 1000그루의 값과 최솟값이 같다. 나무를 더 늘리면 검증 MSE가 더 낮아질 수 있어, 이 표만으로 작은 학습률이 성능을 떨어뜨린다고 결론 내릴 수 없다. 학습률과 나무 수는 함께 정해야 한다.
  3. 240그루는 검증 자료로 고른 값이므로 11.9는 그 검증 자료에 유리하게 골라진 값이다. 설정을 모두 정한 뒤 한 번도 쓰지 않은 테스트 자료로 계산한 MSE를 최종 성능으로 보고한다.

흔한 오답은 가장 작은 최소 검증 MSE만 비교하고 그 값이 어느 나무 수에서 나왔는지는 보지 않는 것이다.

문제 4

깊이 비교와 무작위성

검증 자료 60개로 깊이 2와 깊이 4를 비교했다. 다른 설정은 같다.

설정최소 검증 MSE
깊이 2, random_state=09.84
깊이 4, random_state=09.71
깊이 4, subsample=0.5, 시드 5개9.3에서 10.4
  1. 깊이 4 나무 하나가 한 단계에서 표현할 수 있는 것을 깊이 2와 비교해 설명한다.
  2. subsample=0.5가 단계마다 하는 일을 적는다.
  3. 첫 두 행의 차이 0.13만으로 깊이 4가 낫다고 결론 내릴 수 있는지 판단하고 근거를 적는다.
해설 펼치기
  1. 깊이 2 나무는 한 단계에서 분할을 두 번까지 거치므로 특성 둘까지의 조합을 표현한다. 깊이 4 나무는 특성 넷까지의 조합을 한 나무 안에서 표현한다.
  2. subsample=0.5는 단계마다 학습 자료의 절반을 비복원추출하고, 그 절반으로 다음 나무 하나를 학습한다. 계산은 줄지만 시드에 따라 결과가 달라진다.
  3. 결론 내리기 어렵다. 검증 자료가 60개뿐이고, 같은 깊이 4에서도 시드만 바꾸면 최소 검증 MSE가 9.3에서 10.4까지 1.1만큼 움직인다. 0.13은 이 흔들림보다 훨씬 작다. 시드나 분할을 바꿔 반복해도 차이가 같은 방향으로 유지되는지 확인해야 한다.

흔한 오답은 표의 숫자가 조금이라도 작은 설정을 항상 더 낫다고 보는 것이다.

문제 5

구현 고르기

관측 300,000개로 분류 모델을 만든다. 특성 income에는 서로 다른 값이 180,000개 있고 일부 관측은 income이 비어 있다.

  1. 비어 있지 않은 값만 볼 때, 모든 값 사이를 검사하는 구현과 max_bins=255로 구간화하는 히스토그램 기반 구현이 한 번의 분할 탐색에서 income에 대해 검사하는 경계 수를 각각 적는다.
  2. 그래디언트 부스팅 구현 가운데 결측값을 대체하지 않고 학습할 수 있는 구현을 고르고, 그 구현이 결측 관측을 분할에서 어떻게 처리하는지 설명한다.
  3. HistGradientBoostingClassifier를 기본 설정으로 쓰면 이 자료에서 조기 종료가 켜지는지 판단한다.
  4. 한 학생이 “구간화는 정보를 버리므로 결과가 항상 나빠진다”고 말했다. 이 주장을 어떻게 고쳐 말해야 하는지 설명한다.
해설 펼치기
  1. 모든 값 사이를 검사하면 서로 다른 값 180,000개 사이의 경계 179,999개를 본다. max_bins=255로 구간화하면 구간 경계 254개 이하만 본다. 관측이 늘어나도 구간 수는 그대로다.
  2. HistGradientBoostingClassifier를 고른다. 결측값을 대체하지 않고 넣을 수 있고, 분할마다 결측 관측을 학습 중 손실을 더 줄이는 쪽 가지로 보낸다. GradientBoostingClassifier는 결측값을 먼저 대체해야 한다.
  3. 켜진다. 기본값 early_stopping="auto"는 관측이 10,000개를 넘으면 조기 종료를 사용한다.
  4. 구간화가 항상 결과를 나쁘게 만든다고 말할 수 없다. 어떤 설정과 자료에서는 모든 값 사이를 검사한 구현의 점수가 조금 높을 수 있지만, 그 차이의 방향과 크기는 자료와 설정에 따라 다르다. 큰 자료에서는 학습 시간이 크게 줄어드는 이점이 있으므로 검증 점수와 학습 시간을 함께 비교해 고른다.

흔한 오답은 결측값이 들어 있으면 항상 해당 관측을 버려야 한다고 판단하는 것이다.
