개념 확인: Clustering and Principal Components

정답 열 없이 K-means로 관측을 묶고 주성분으로 특성을 요약하는 계산과 해석을 연습한다.

문제 1

정답 없이 묻기

  1. ‘비슷한 고객을 묶고 싶다’와 ‘설문 30문항을 적은 축으로 요약하고 싶다’에 각각 알맞은 방법과 그 결과물을 적는다.
  2. 정답 범주가 없는 자료에서 분류 정확도를 계산할 수 없는 이유와 대신 점검할 것 두 가지를 적는다.
  3. 두 번 실행한 K-means의 군집 번호가 관측 1~4에서 (0, 0, 1, 2)와 (2, 2, 0, 1)이었다. 두 결과가 같은 분할인지 판단한다.
  4. 군집 번호를 이미 있는 범주 번호(0, 1, 2)와 그대로 대조해 정확도를 계산하면 안 되는 이유를 적는다.
해설 펼치기
  1. 고객 묶기는 군집화로 관측별 군집 배정을, 문항 요약은 주성분분석으로 새 축의 방향(적재량)과 관측의 좌표(점수)를 얻는다.
  2. 예측과 대조할 정답이 없기 때문이다. 설정한 거리와 목적함수로 본 군집의 응집도, 자료·초기값 변화에 대한 결과의 안정성과 사용 목적을 점검한다.
  3. 같은 분할이다. 관측 1과 2가 함께 묶이고 3과 4가 각각 다른 군집인 구조가 같고 번호만 다르다.
  4. 군집 번호에는 순서나 뜻이 없고 군집은 정답 범주와 일치해야 하는 것도 아니므로, 번호를 맞대면 같은 분할도 정확도가 다르게 계산된다.
문제 2

K-means 손으로 돌리기

1차원 관측 1, 2, 4, 9, 11, 12에 K = 2 K-means를 초기 중심 2와 4에서 시작한다.

  1. 첫 배정과, 그 배정에서 중심을 평균으로 갱신한 값, 갱신 후 목적함수(제곱거리 합)를 구한다.
  2. 다시 배정하고 중심을 갱신한 값과 목적함수를 구한다(소수 셋째 자리까지).
  3. 배정이 더 바뀌는지 확인하고, 목적함수 값이 반복마다 어떻게 변했는지 적는다.
  4. 다른 초기 중심에서 시작하면 더 큰 목적함수 값에서 멈출 수 있다. 이를 실제로 어떻게 다루는지 적는다.
해설 펼치기
  1. 1, 2는 중심 2, 4·9·11·12는 중심 4에 배정된다. 새 중심 1.5와 9, 목적함수 0.5 + (25 + 0 + 4 + 9) = 38.5다.
  2. 4는 1.5까지 2.5, 9까지 5이므로 첫 군집으로 옮긴다. 새 중심 7/3 ≈ 2.333과 32/3 ≈ 10.667, 목적함수 14/3 + 14/3 = 28/3 ≈ 9.333이다.
  3. 배정이 바뀌지 않아 멈춘다. 목적함수는 초기 139에서 38.5, 19.75(재배정 직후), 9.333으로 늘지 않고 줄었다.
  4. 한 번의 실행은 전역 최적을 보장하지 않으므로 여러 초기값(n_init)에서 실행해 같은 자료·같은 K에서 목적함수가 가장 작은 결과를 고른다.
문제 3

K와 척도

같은 표준화 자료에서 K별로 여러 초기값 중 가장 작은 목적함수 값을 기록했다.

K12345
목적함수10040252220
  1. 목적함수가 가장 작은 K를 고르는 규칙의 문제를 관측마다 한 군집일 때의 값으로 설명한다.
  2. K가 하나 늘 때마다 줄어든 양을 구하고, 감소가 완만해지는 자리를 적는다.
  3. 군집 세 개가 필요하다는 업무 기준이 따로 있다면 K를 어떻게 정하는지 적는다.
  4. 나이(년)와 소득(원)을 그대로 넣었을 때 K-means가 무엇을 주로 기준으로 묶는지와, 표준화가 ‘모델링 선택’인 이유를 적는다.
해설 펼치기
  1. K를 늘리면 최솟값은 커지지 않고 관측마다 한 군집이면 0이 되므로 항상 가장 큰 K가 선택된다.
  2. 60, 15, 3, 2다. K = 3 이후 감소가 완만해진다.
  3. 문제가 정해 준 집단 수가 가장 분명한 근거이므로 K = 3을 쓰고, 결과 군집이 뜻이 통하는지 확인한다.
  4. 소득 차이의 제곱이 수치적으로 훨씬 커서 소득이 거리를 지배한다. 표준화는 특성별 표준편차 단위로 차이를 비교하겠다는 결정이며, 무엇을 비슷하다고 볼지 정하는 선택이다.
문제 4

주성분 계산

두 특성을 중심화한 자료에서 첫 주성분 적재량이 φ₁ = (0.6, 0.8)이다.

  1. φ₁이 단위벡터인지 확인하고, 중심화한 관측 (2, 1)과 (−1, 3)의 첫 주성분 점수를 구한다.
  2. φ₁에 직교하는 단위 적재량 φ₂ 하나를 적는다.
  3. 특성 10개일 때 두 특성씩 짝지은 산점도 수를 구한다.
  4. 다섯 주성분의 분산이 5, 2, 1.5, 1, 0.5일 때 PVE와 누적 PVE를 구하고, ‘누적 80% 이상’ 규칙으로 남길 축 수와 그 규칙의 한계를 적는다.
해설 펼치기
  1. 0.6² + 0.8² = 1이다. 점수는 0.6 × 2 + 0.8 × 1 = 2.0과 0.6 × (−1) + 0.8 × 3 = 1.8이다.
  2. (0.8, −0.6)이다(부호를 바꾼 (−0.8, 0.6)도 된다). 내적이 0이고 길이가 1이다.
  3. 10 × 9/2 = 45개다.
  4. PVE 0.5, 0.2, 0.15, 0.1, 0.05, 누적 0.5, 0.7, 0.85, 0.95, 1.0이므로 3개다. 80%라는 비율도 사람이 정하며, 분산을 보존해도 분류에 필요한 정보의 보존은 보장하지 않는다.
문제 5

둘을 함께 쓸 때

USArrests 네 특성을 표준화한 뒤 PC1·PC2 점수로 K = 3 군집을 구했다. 누적 PVE는 PC2까지 0.868이다.

  1. 표준화하지 않고 PCA를 하면 PC1이 어떻게 달라질 수 있는지 Assault의 단위와 연결해 적는다.
  2. 두 축에서 군집화할 때 사용하지 않은 분산 비율을 구하고, 그 결과 생길 수 있는 문제를 적는다.
  3. 세 군집을 ‘치안 유형’이라고 이름 붙이기 전에 확인할 것을 적는다.
  4. 주성분을 예측 모델의 전처리로 쓸 때 자료 분할 전에 전체 자료로 주성분을 추정하면 무엇이 문제인지 적는다. 주성분 점수가 서로 독립이라고 말할 수 있는지도 적는다.
해설 펼치기
  1. 원래 척도에서는 분산이 큰 Assault의 영향이 PC1을 지배할 수 있다. 표준화 여부에 따라 주성분 방향이 달라진다.
  2. 1 − 0.868 = 0.132, 즉 13.2%다. 버린 방향에 있던 구분이 사라질 수 있다.
  3. 원래 특성의 군집별 분포로 그 해석을 뒷받침해야 한다. 설명은 사람이 붙인 것이다.
  4. 테스트 자료 정보가 축 추정에 들어가 데이터 누수가 된다. 먼저 나누고 학습 자료에서만 주성분을 추정한다. 점수는 선형 상관이 없지만 반드시 독립은 아니다.
