Supervised Data

지도학습 자료는 입력 x와 그에 대응해 관측된 출력 y를 짝지은 학습 사례의 모음이다. 모델이 계산한 예측값 ŷ는 기록된 y와 구별한다.

학습 사례 (x⁽ⁱ⁾, y⁽ⁱ⁾)i번째 사례의 입력과 관측된 출력의 쌍이다.
출력 y측정, 사람의 판정, 이후에 일어난 결과를 기록해 얻는다.
예측값 ŷ모델이 입력에서 계산한 값 ŷ⁽ⁱ⁾ = f̂(x⁽ⁱ⁾)다.

한 행이 입력 x⁽ⁱ⁾와 출력 y⁽ⁱ⁾의 쌍이다

사례 번호 i를 바꾸면 학습 자료에서 강조되는 행과 그 행의 x⁽ⁱ⁾, y⁽ⁱ⁾가 바뀐다.

예측값 ŷ는 관측된 y와 어긋날 수 있다

모델의 예측 규칙을 바꾸면 각 사례의 ŷ가 다시 계산되고, 관측된 y와 어긋난 사례가 바뀐다.
