Predicting a Probability↗

개념 확인: Logistic Regression

선형 점수를 로그 승산·확률·범주로 차례로 바꾸고 결정 기준을 점검한다.

문제 1, 2, 5의 모델은 잔액 x(백만 원)로 연체 여부를 예측하며 로그 승산이 z = −4 + 0.8x다. 계산에는 e⁰·⁸ ≈ 2.23, e⁴ ≈ 54.6을 쓴다. 로그는 자연로그다.

문제 1

점수, 승산, 확률

  1. x = 0, 5, 10일 때 선형 점수 z를 구한다.
  2. 각 x에서 승산 eᶻ와 확률 p = σ(z)를 구한다(소수 셋째 자리까지).
  3. 확률·승산·로그 승산의 범위를 적는다.
  4. 같은 자료에 선형 회귀로 확률을 예측하면 생길 수 있는 문제 두 가지를 적는다.
해설 펼치기
  1. z(0) = −4, z(5) = −4 + 4 = 0, z(10) = −4 + 8 = 4다.
  2. x = 0: 승산 e⁻⁴ ≈ 1/54.6 ≈ 0.018, 확률 1/(1 + 54.6) ≈ 0.018. x = 5: 승산 1, 확률 0.5. x = 10: 승산 약 54.6, 확률 54.6/55.6 ≈ 0.982.
  3. 확률 (0, 1), 승산 (0, ∞), 로그 승산 실수 전체다.
  4. 예측값이 0보다 작거나 1보다 커져 확률로 해석할 수 없다. 이진 결과의 분산 p(1 − p)가 확률에 따라 달라 조건부 분산이 일정하지 않다.
문제 2

계수 0.8의 뜻

  1. 다른 조건이 같을 때 x가 1 증가하면 로그 승산과 승산이 어떻게 바뀌는지 적는다.
  2. x가 5에서 6으로, 10에서 11로 늘 때 확률의 증가량을 구한다. σ(0.8) ≈ 0.690, σ(4.8) ≈ 0.992다.
  3. 두 증가량이 다른 이유를 sigmoid 함수의 구간별 기울기로 설명한다.
  4. 학생 여부 s(학생 = 1)만 넣은 모델에서는 s의 계수가 양수였는데, 잔액 x를 함께 넣은 모델에서는 s의 계수가 음수가 되었다. 학생은 잔액이 큰 경우가 많다. 두 결과가 모순이 아닌 이유를 적는다.
해설 펼치기
  1. 로그 승산은 0.8 더해지고 승산은 e⁰·⁸ ≈ 2.23배가 된다.
  2. 5 → 6: 0.690 − 0.5 = 0.190. 10 → 11: 0.992 − 0.982 = 0.010.
  3. sigmoid는 z = 0 근처에서 가파르고 양 끝에서 완만하다. 확률이 0.5 근처면 크게 변하고 1에 가까우면 거의 변하지 않는다. 계수를 확률의 고정 증가량으로 읽지 않는다.
  4. 두 계수는 다른 질문에 답한다. s만 넣으면 잔액이 큰 학생이 많다는 사실까지 섞여 학생 전체의 연체율이 높게 나타난다. 잔액을 함께 넣은 계수는 같은 잔액끼리 비교한 차이라서, 같은 잔액에서는 학생의 연체율이 더 낮다는 뜻이다.
문제 3

우도와 손실로 계수 비교하기

두 관측의 정답이 y₁ = 1, y₂ = 0이다. 두 모델이 각 관측의 Y = 1 확률을 다음과 같이 예측했다.

모델관측 1의 p관측 2의 p
A0.90.2
B0.60.6
  1. 각 모델에서 정답 범주에 준 확률을 곱해 우도를 구한다.
  2. 모델 A의 손실 ℓ(y, p) = −y log p − (1 − y) log(1 − p)를 관측마다 구하고 더한다(−log 0.9 ≈ 0.11, −log 0.8 ≈ 0.22). 모델 B의 손실 합은 약 1.43이다.
  3. 로지스틱 회귀의 추정 기준으로 더 나은 모델을 적고 선형 회귀의 기준과 비교한다.
해설 펼치기
  1. A: 관측 1의 정답 확률 0.9, 관측 2의 정답(0) 확률 1 − 0.2 = 0.8이므로 0.9 × 0.8 = 0.72. B: 0.6 × (1 − 0.6) = 0.24다.
  2. A: −log 0.9 ≈ 0.11, −log 0.8 ≈ 0.22로 합은 약 0.33이다.
  3. 우도를 최대화, 곧 손실(정답 범주에 준 확률의 음의 로그)의 합을 최소화하므로 우도 0.72, 손실 0.33인 A가 우도 0.24, 손실 1.43인 B보다 낫다. 손실의 합은 음의 로그 우도와 같아서 0.33 ≈ −log 0.72, 1.43 ≈ −log 0.24다. 선형 회귀는 RSS를 최소화한다. 두 확률이 같은 B가 안전한 것이 아니며, 정답 범주에 낮은 확률을 줄수록 손실이 커진다.
문제 4

임계값을 바꾸면

다섯 고객의 예측 확률과 실제 연체 여부다.

고객12345
예측 확률0.850.450.350.250.05
실제 연체예예아니오예아니오
  1. 임계값 0.5, 0.3, 0.2에서 연체로 예측하는 고객을 적는다(예측 확률이 임계값 이상이면 연체).
  2. 각 임계값에서 실제 연체를 놓친 수와 연체로 잘못 분류한 수를 센다.
  3. 임계값을 낮출 때 두 오류의 변화와, 임계값을 정할 자료와 기준을 적는다.
해설 펼치기
  1. 0.5: 고객 1. 0.3: 고객 1, 2, 3. 0.2: 고객 1, 2, 3, 4.
  2. 0.5: 놓침 2(고객 2, 4), 잘못 분류 0. 0.3: 놓침 1(고객 4), 잘못 분류 1(고객 3). 0.2: 놓침 0, 잘못 분류 1(고객 3).
  3. 놓치는 오류는 줄거나 유지되고 잘못 분류하는 오류는 늘거나 유지된다. 오류 비용과 목적을 고려해 검증 자료에서 정한다.
문제 5

결정 경계와 정확도

  1. 임계값 0.5에서 문제 1 모델의 결정 경계가 되는 잔액 x를 구한다.
  2. 로그 승산이 z = −6 + x₁ + 2x₂인 모델의 임계값 0.5 결정 경계 식과 모양을 적는다.
  3. 고객 1,000명 중 20명만 연체한 자료에서 모두 ‘연체 아님’으로 예측하는 모델의 정확도와, 이 정확도로 판단하면 안 되는 이유를 적는다.
  4. 한 범주가 다른 범주를 원 모양으로 감싸는 자료에서 로지스틱 회귀의 한계를 적는다.
해설 펼치기
  1. 임계값 0.5는 로그 승산 0이므로 −4 + 0.8x = 0, 곧 x = 5다.
  2. −6 + x₁ + 2x₂ = 0, 곧 x₁ + 2x₂ = 6인 평면 위의 직선이다.
  3. 980/1,000 = 98%다. 실제 연체 20명을 모두 놓치므로 정확도 하나로 판단할 수 없다.
  4. 결정 경계가 직선이라 감싸는 모양을 분리할 수 없어 과소적합한다. 모델이나 특성을 바꾸어야 한다.
