Learning and Generalization

학습 오차와 새 자료의 오차를 구분하고 모델의 상태를 진단한다.

문제 1

테스트 자료의 역할

한 학생이 다음 순서로 모델을 만들었다.

  1. 전체 자료를 학습 자료와 테스트 자료로 나눴다.
  2. 학습 자료로 모델 A를 적합했다.
  3. 테스트 오차를 확인했다.
  4. 테스트 오차가 커서 모델 구조를 바꾸고 같은 테스트 자료를 다시 확인했다.
  5. 가장 낮은 테스트 오차를 최종 성능으로 보고했다.

독립적인 최종 평가를 깨뜨린 단계를 찾고, 그 단계가 왜 문제인지와 테스트 자료를 어떤 원칙으로 사용해야 하는지 설명한다. 이 성능을 보고할 때 함께 밝혀야 할 정보 두 가지도 적는다.

해설 펼치기

4단계부터 테스트 자료가 모델 선택에 사용되었고, 5단계의 값은 독립적인 최종 평가가 아니다. 테스트 결과를 보고 구조를 바꾸면 모델이 테스트 자료의 특성에도 맞춰진다.

테스트 자료는 모델을 정하는 동안 보지 않고 최종 성능을 한 번 평가하는 데 남겨 둔다. 성능을 보고할 때는 평가에 쓴 자료(테스트 자료를 한 번만 썼는지)와 테스트 관측 수를 함께 밝힌다. 여러 모델을 비교했다면 비교한 횟수도 밝힌다.

문제 2

두 오차 계산하기

어떤 회귀 모델의 잔차 y − ŷ가 학습 자료에서 0, 1, −1, 0, 테스트 자료에서 2, −2다.

  1. 학습 MSE와 테스트 MSE를 계산한다.
  2. 두 값의 차이만 보고 알 수 있는 것과 아직 단정할 수 없는 것을 각각 적는다.
  3. 다른 분류 모델은 테스트 관측 8개 가운데 2개를 잘못 분류했다. 테스트 오류율을 구하고, MSE 대신 오류율을 써도 자료를 나누는 원칙이 같은지 적는다.
해설 펼치기
  1. 학습 MSE = (0² + 1² + (−1)² + 0²)/4 = 0.5, 테스트 MSE = (2² + (−2)²)/2 = 4다.
  2. 이 분할에서는 테스트 자료의 오차가 더 컸고 모델이 학습 자료에 더 잘 맞았을 가능성을 의심할 수 있다. 테스트 관측이 2개뿐이고 다른 복잡도와 비교하지 않았으므로 과적합의 정도나 일반화 오차를 확정할 수는 없다.
  3. 오류율 = 틀린 수/관측 수 = 2/8 = 0.25다. 원칙은 같다. 학습에 쓰지 않은 자료에서 재야 새 자료의 성능을 추정한다.
문제 3

줄일 수 없는 오차

관측값이 Y = f(X) + ε를 따르고 ε은 X와 독립이고 𝔼(ε) = 0, Var(ε) = 9라고 하자. 모델이 f를 정확히 알아내 Ŷ = f(X)로 예측한다.

  1. 이 모델의 제곱 예측 오차의 기댓값 𝔼[(Y − Ŷ)²]이 0이 될 수 있는지 적는다.
  2. 모델을 더 복잡하게 만들면 Var(ε)를 줄일 수 있는지 적는다.
  3. 줄일 수 있는 오차와 줄일 수 없는 오차를 식의 항으로 구분한다.
해설 펼치기
  1. 될 수 없다. Y − Ŷ = ε이므로 𝔼[(Y − Ŷ)²] = Var(ε) = 9가 남는다. 부호가 있는 오차 ε의 기댓값은 0이지만 제곱 오차의 기댓값은 0이 아니다.
  2. 줄일 수 없다. 모델 복잡도는 f̂가 f를 얼마나 잘 근사하는지에만 영향을 주고 관측 과정의 잡음 분산은 없애지 못한다.
  3. [f(x) − f̂(x)]²는 모델을 바꾸어 줄일 수 있는 오차, Var(ε)는 f를 정확히 알아도 남는 줄일 수 없는 오차다.
문제 4

세 모델의 상태

같은 학습 자료로 복잡도가 다른 세 모델을 적합하고, 학습에 쓰지 않은 별도 자료에서도 MSE를 쟀다. 최종 평가용 테스트 자료는 따로 남겨 두었다.

모델학습 MSE학습에 쓰지 않은 자료의 MSE
A9.010.0
B2.03.0
C0.18.0
  1. 과소적합의 증상이 가장 강한 모델을 고르고 편향·분산 가운데 주된 원인을 적는다.
  2. 과적합의 증상이 가장 강한 모델을 고르고 주된 원인을 적는다.
  3. 세 모델 가운데 고를 모델을 적고, 고른 뒤에도 따로 남긴 테스트 자료로 한 번 더 평가해야 하는 이유를 적는다.
  4. C를 보고 ‘학습 오차가 거의 0이니 완성이다’라고 한 주장의 문제를 적는다.
해설 펼치기
  1. A다. 두 오차가 모두 커서 편향이 큰 증상이다. 잡음이 큰 경우에도 두 오차가 함께 클 수 있다.
  2. C다. 학습 오차는 매우 작지만 학습에 쓰지 않은 자료의 오차가 커서 분산이 큰 증상이다.
  3. B다. 이 표는 선택에 쓰였으므로 선택 과정의 영향이 남는다. 선택을 마친 모델의 성능은 선택에 쓰지 않은 테스트 자료로 따로 재야 한다.
  4. 학습 오차만 보고 판단했다. C는 학습에 쓰지 않은 자료의 MSE가 8.0으로 B의 3.0보다 크다. 학습 자료의 잡음까지 따라가면 학습 오차는 0에 가까워도 새 자료의 오차는 커질 수 있다.
문제 5

편향과 분산

같은 입력 x₀에 대해 학습 자료를 여러 번 새로 뽑아 모델을 다시 적합했다. 참 함수값은 f(x₀) = 𝔼(Y ∣ X = x₀) = 50이다.

  • 방법 P의 예측: 39, 40, 41, 40
  • 방법 Q의 예측: 30, 68, 45, 61
  1. 구조적으로 같은 방향으로 빗나가는 증상이 더 강한 방법을 고르고 편향·분산과 연결한다.
  2. 학습 자료가 달라질 때 적합이 흔들리는 증상이 더 강한 방법을 고르고 편향·분산과 연결한다.
  3. 방법 Q의 흔들림을 키울 수 있는 조건 세 가지를 적는다.
해설 펼치기
  1. P다. 예측이 40 부근에 모여 있지만 참 함수값 50보다 계속 작아 편향이 큰 증상이다.
  2. Q다. 학습 자료가 바뀔 때 예측이 30에서 68까지 달라져 분산이 큰 증상이다. 평균이 50 주변이어도 흔들림이 크다.
  3. 관측이 적을 때, 모델이 매우 복잡할 때, 관측 잡음이 클 때다. 분산은 모델 복잡도, 관측 수, 잡음의 크기에 함께 좌우된다.
